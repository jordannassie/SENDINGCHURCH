# Sending Church

Next.js app with Supabase, deployed on Netlify.

## Local setup

```bash
npm install
cp .env.local.example .env.local
npm run dev
```

Fill `.env.local` from the Supabase project dashboard (Project Settings → API).

## Frisco lead tracker

`/csv` is the Meta CSV importer. It does not require a login. The footer CSV link opens that page.

Keep `NEXT_PUBLIC_SUPABASE_URL` and `NEXT_PUBLIC_SUPABASE_ANON_KEY` (or `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`) in the environment. Do not put the service-role key in the browser.

If Supabase says `sending_leads` is missing from the schema cache, run `supabase/sending_leads.sql` in that project's SQL editor. The live site uses `https://eeeprmtermreavivzswn.supabase.co`.

Imports insert new rows only (`onConflict: phone_normalized`, `ignoreDuplicates: true`). `phone_normalized` is generated by the database and is never written by the app.
